# 项目审查与优化报告（2026-08-06）

> 本报告记录了 `daily-stock-review` 项目的代码审查结论、2026-08-06 优化落实情况，
> 以及优化前后回测对比与近半年窗口校验结果。完整页面入口见 [docs.html](../docs.html)。

## 一、审查结论摘要

### 总体评价
工程底子不错：纯标准库零依赖、数据流清晰（腾讯/东财/新浪公开接口 → 分析 → JSON → 静态页）、
回测无重大未来函数。但逻辑层面存在几个硬问题，其中一个是核心闭环矛盾。

### 1. 回测结论与推荐逻辑自相矛盾（P0，已修）
旧版网格策略回测（13 只红利标的）：**平均年化 2.58%，平均超额 -17.6%**——
网格在趋势性红利股上大幅跑输买入持有（长江电力超额 -73%、神华 -67%、陕煤 -48%）。
但 recommend/holdings 页面每天推送该策略的加仓/减仓提醒。

**根因**：
- 网格步长固定 0.5%，而标日波动 1.5~2% → 过度交易（长江电力 6 年 1012 次交易）
- 上行趋势中"越涨越抛"削掉收益（仓位随 dev 线性下降，dev+15% 时只剩 40% 仓位）
- 半永久锁仓宣称"反弹不回吐"，但代码中 `lock` 变量从未参与仓位计算（摆设）

### 2. 锁仓机制未生效（P0，已修）
`grid_backtest.py` 中 `lock` 只被计算和记录，`position_target()` 从不使用它。

### 3. 估值缓存无 TTL（P0，已修）
`fetch_stock_value_em()` 把网络失败永久缓存为空数组且永不刷新 → 一次失败导致
估值锚静默退化为价格锚，页面无提示。

### 4. 其他问题（已修 / 部分已修）
- RSI 打分与趋势系统哲学冲突：超卖给满分、超买给 0 分（均值回归思维混入趋势系统）→ 已修正
- 止损 MA20 一刀切，不区分个股波动 → 已增加 ATR 止损
- 价值因子跨行业比较（银行永远"便宜"）→ 已改板块内分位
- 动量双重计费（技术分 + 横截面分）→ 已降权
- 板块打分用绝对 PE（5 - pe/12）→ 已改跨板块分位
- 复盘跟踪依赖 git 历史（脆弱、仅 4 天数据）→ 已改 SQLite 持久化
- `scripts/serve.py` 硬编码 `/home/smas/...` 路径 → 已改为脚本相对路径
- `backtest/159131_5min_optimal.html`（样本内过拟合报告）→ 已删除
- 大盘温度计用 250 只自选池广度（有偏）→ 未改（全市场广度数据源待接入，见待办）

### 5. 未修复的遗留问题（诚实声明）
- 网格策略整体仍跑输买入持有（见下节数据）——这是均值回归策略的固有问题：
  **它只在震荡市有效，趋势市天然吃亏**。当前定位应为"辅助仓位管理工具"，
  不应对其抱有超额收益期望。
- 回测池 13 只为手挑红利标的，存在幸存者偏差，结论不可外推。
- 无滑点建模（红利大票影响小，可接受）。
- 温度计全市场广度待接入；akshare 数据源未接入（见待办）。

## 二、优化落实明细（2026-08-06）

### src/indicators.py
- 新增 `true_range` / `atr`（Wilder ATR14）——波动自适应
- 新增 `adx`（Wilder ADX14）——趋势/震荡状态识别

### src/grid_backtest.py
- **ATR 动态步长**（`dynamic_step=True`，默认）：步长 = 1.2 × ATR14/收盘价，
  取近 250 日中位数，夹在 [1%, 3%]。替代固定 0.5%
- **真锁仓**（`use_lock=True`，默认）：dev ≤ -5% 后加仓累入锁仓下限，
  反弹时仓位不低于下限；dev ≥ +5% 解锁
- **ADX 趋势闸门**（`adx_gate`，默认**关闭**，实验开关）：开启时 ADX > 25
  冻结调仓。回测显示该闸门在低波 ETF 上过度冻结拖累收益（详见下节），
  故默认关闭，保留供参数实验
- **估值缓存 TTL**：非空结果 24h、空结果 6h，到期自动重试；失败时回退过期旧数据
- 回测结果新增 `grid_step` 字段（记录实际使用的步长）

### src/grid_signal.py
- `compute_grid_signal` / `signal_from_backtest` 与回测口径对齐（ATR 动态步长）

### src/analyzer.py
- **RSI 打分趋势化**：强势 10 / 中性 6 / 超买 5 / 弱势 3 / 超卖 2
  （旧版超卖 10 / 超买 0 是均值回归思维，会系统性压分强势股）
- **ATR 止损**：新增 `atr14` / `atr_stop`（止损 = 收盘价 - 2 × ATR14），
  与 MA20 止损并存展示

### src/screener.py
- **价值因子板块内分位**：同行业才可比（银行 PE~6 与科技 PE~50 不再混排），
  板块样本 < 5 时回退全池分位
- **动量降权去重**：当日动量从 50% 降到 30%（单日动量是噪音）；
  横截面动量权重 27.5% → 20%（技术分已含趋势，避免双重计费）；
  价值升权至 30%、稳定性 20%、流动性 15%、活跃度 15%

### run_review.py
- 板块打分：绝对 PE（5 - pe/12）→ **跨板块 PE 分位**，估值档位升权，当日动量降权

### build_tracking.py
- **SQLite 持久化**（`data/tracking.db`）：每日推荐快照自动追加入库，
  git 历史仅作首次一次性导入（幂等），不再依赖 git 历史
- 每次运行自动快照当日推荐 → 推荐命中率统计不再依赖提交频率

### scripts/serve.py
- 修复硬编码路径：项目根目录改为由脚本位置推导

## 三、回测对比（优化前 vs 优化后）

口径：13 只红利标的，3200 根日K（前复权），单边成本 0.05%，基准 = 满仓买入持有。
"旧" = 固定 0.5% 步长 + 无锁仓；"新" = ATR 动态步长 + 真锁仓（最终默认参数）。

| 标的 | 旧年化 | 新年化 | 旧回撤 | 新回撤 | 旧交易 | 新交易 | 新步长 |
|---|---|---|---|---|---|---|---|
| 中证红利ETF招商 | 6.1% | 6.0% | -7.8% | -9.9% | 649 | 404 | 1.28% |
| 红利低波ETF富国 | -0.1% | -0.8% | -9.9% | -10.1% | 197 | 107 | 1.32% |
| 红利ETF汇添富 | 6.6% | 5.8% | -9.4% | -10.0% | 254 | 125 | 1.48% |
| 陕西煤业 | -0.7% | **+7.5%** | -36.8% | -29.3% | 214 | 356 | 3.00% |
| 中国神华 | 11.4% | **+15.4%** | -20.6% | -18.3% | 521 | 388 | 2.86% |
| 长江电力 | 7.1% | **+8.9%** | -15.4% | -15.0% | 1012 | 671 | 1.46% |
| 煤炭ETF国泰 | 11.6% | 6.6% | -16.6% | -19.9% | 670 | 331 | 3.00% |
| 招商银行 | 4.8% | **+5.7%** | -51.3% | -48.0% | 885 | 627 | 1.96% |
| 宁波银行 | 3.5% | **+5.1%** | -50.0% | -44.1% | 733 | 612 | 2.73% |
| 平安银行 | -1.8% | -1.1% | -54.7% | -53.5% | 680 | 698 | 1.74% |
| 中国人寿 | -0.7% | **+4.4%** | -40.9% | -41.5% | 314 | 594 | 3.00% |
| 中国人保 | 2.4% | **+3.5%** | -38.7% | -32.9% | 645 | 358 | 3.00% |
| **平均** | **2.58%** | **3.07%** | **-27.6%** | **-26.2%** | **524** | **407** | — |

**解读**：
- 平均年化 +0.49pp、平均回撤改善 1.4pp、交易次数 -22%（旧 649→新 404 等）
- 个股（有估值锚）全部改善或持平：陕煤 +8.2pp、神华 +4.0pp、长电 +1.8pp、国寿 +5.1pp
- ETF 系小幅退步（-0.1~-0.8pp）：低波动资产 ATR 小、动态步长收益有限，
  且锁仓在窄幅震荡中限制了低吸灵活性——这是均值回归策略的固有折中
- 煤炭ETF 退步最大（11.6%→6.6%）：该标的历史波动大但呈宽幅震荡，
  旧版密集网格恰好最有效，动态步长（达 3% 上限）削弱了网格密度

**ADX 闸门实验（不采用，留作开关）**：
| 变体 | 年化 | 回撤 | 交易 | 半年超额 |
|---|---|---|---|---|
| 旧（固定0.5%） | +2.58% | -27.6% | 524 | -1.75% |
| 新（ATR步长+锁仓，最终默认） | **+3.07%** | **-26.2%** | 407 | **-0.85%** |
| 新 + ADX闸门(25) | +2.86% | -26.4% | 272 | -0.95% |
| 新 + ADX闸门(30) | +2.97% | -26.3% | 326 | -0.91% |

ADX 闸门虽然大幅减少交易次数，但在低波 ETF 上过度冻结，收益反而不如不带闸门，
故默认关闭（`GridParams(adx_gate=True)` 可随时开启实验）。

## 四、近半年（约 126 交易日）窗口校验

校验逻辑：取每只标的回测净值序列最后 126 根K线，计算策略收益 - 基准收益（超额），
与全周期结论对照。

| 标的 | 旧半年超额 | 新半年超额 |
|---|---|---|
| 中证红利ETF招商 | +1.0% | +0.2% |
| 红利低波ETF富国 | +0.5% | -0.1% |
| 红利ETF汇添富 | +1.1% | +0.2% |
| 陕西煤业 | -19.4% | -7.2% |
| 中国神华 | -4.3% | -2.3% |
| 长江电力 | -0.2% | -2.5% |
| 煤炭ETF国泰 | +2.2% | -3.2% |
| 招商银行 | -0.9% | -1.2% |
| 宁波银行 | -1.2% | -1.9% |
| 平安银行 | -2.2% | -2.0% |
| 中国人寿 | 0.0% | **+3.1%** |
| 中国人保 | +2.5% | **+5.4%** |
| **均值** | **-1.75%** | **-0.85%** |
| 跑赢基准 | 6/12 | 5/12 |

**结论（重要，诚实版）**：
1. 优化后半年超额从 -1.75% 改善到 -0.85%，**但仍平均跑输买入持有**
2. 跑赢/跑输基准约各半 → 近半年（2026-02 至 2026-08）红利股整体处于
   震荡偏弱市，网格策略只是"少亏"，没有产生超额
3. **这验证了审查报告的判断：均值回归网格策略只有在震荡市才有效。
   把它当"辅助仓位管理"而非"超额收益来源"，是使用该策略的正确姿势**
4. 近半年窗口仅 126 个交易日，单窗口结论不能外推；应持续用
   `tracking_data.json`（SQLite 快照）积累 60~100 天以上推荐命中率后再做统计结论

## 六、模型 / Skill 建议

1. **LLM 复盘 Skill**（本项目配套 `.opencode/skills/daily-stock-review/SKILL.md`）：
   规则系统只能回答"买什么形态"，回答不了"为什么涨/跌"。Skill 每日读取
   `data/*.json` + 联网抓宏观新闻（非农/CPI/议息/行业政策），输出叙事版复盘、
   风险提示、事件日历，与规则系统互补。
2. **暂不引入 ML**：250 只自选池 + 短历史，LightGBM 排序只会过拟合。
   若未来扩到全市场（akshare）+ 积累 100 天以上标注数据，再做 walk-forward 验证。
3. **指标层已完成**：ATR（止损/步长）、ADX（状态识别）已实现；ERP
   （1/沪深300PE − 10Y 国债）可作温度计升级方向。
