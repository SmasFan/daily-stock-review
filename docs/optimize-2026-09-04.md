## 手机远程终端滚动查看方法（补充）

根因：pi 默认 **regular 模式** = 用终端自身 scrollback，滚轮/滑屏被手机 SSH 客户端吞掉，pi 收不到滚动 → 翻不了记录。

**方案（推荐）：切 fullscreen 模式**
- 运行 `pi` 时加参数：`pi --tui-mode fullscreen`（或进 pi 后 `/settings` 把 TUI mode 改 fullscreen，立即生效并记住）
- fullscreen 下 pi 自己接管视口，transcript 在固定 dock 上独立滚动：
  - 双指滑 / 滚轮滚指针所在区域
  - 键盘：`pageUp/pageDown` 翻页、`home/end` 到头/尾、`ctrl+shift+f` 搜索记录
- 手机 SSH 客户端需支持把滚轮/触摸板事件发给远端：
  - Termius / JuiceSSH（Android）：设置里开 mouse/trackpad 转发
  - Blink / Secure Shellfish（iOS）：支持 trackpad 滚动转发
  - 不支持的客户端 → 键盘 pageUp/pageDown 一定可用

**备选（纯键盘，无鼠标也行）**
- fullscreen 内 `ctrl+shift+f` 全文搜索，直接跳关键词（比翻屏快）
- `ctrl+up / ctrl+down` 在消息间跳转
- regular 模式也可用：让手机 SSH 客户端发 pageUp/pageDown（大多数支持软键盘）

**手机上最省事**：用 GitHub 网页/客户端看仓库 `docs/` 或 session JSONL，不依赖终端滚动。
