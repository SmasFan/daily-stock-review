# 模块优化总结 2026-09-04

已提交 37e57f1 并推送。94 单测全绿。

## 改了什么

1. **网格信号不再重复拉数据（最大收益）**
   - 旧：`build_grid_signals` 按「名称」找 `data/backtest_data.json`（文件已拆分成小文件，根本不存在）
     → 每只候选股每天重新拉 3200 根长K线 + 估值，耗时且易被限流
   - 新：按「代码」匹配 `data/backtest/{名称}.json` 拆分文件，自动读 `backtest_index.json`
     → 推荐 141 只候选里 134 只直接复用当日盘后结果，几乎零网络请求
   - 持仓模块同样复用，不再现场重算

2. **网格信号现价修复**
   - 旧：`signal_from_backtest` 的 close 恒为 None
   - 新：从拆分文件取真实收盘价，页面价格准确

3. **去重复**
   - 复盘/推荐两块「普涨过热+低温闸门」约 60 行重复 → 抽成 `compute_breadth_ratio` / `_regime_warn` / `load_backtest_prev` 共用
   - 财务指标 key 映射 3 处重复 → `ths_api.extract_financial_summary()`
   - `build_lowval.pct_rank` O(n²) → 复用 `screener.rank_pct` O(n log n)
